ARKANSAS PATROL CHARGE TRIAGE V2.3 — FIELD MODE

DESIGN GOAL
Get the officer from facts to a charge quickly, without scrolling through a legal worksheet.

WHAT CHANGED
• One question on screen at a time.
• Progress bar + Back / Next.
• No long list of report questions during initial charge triage.
• Every question has a HELP button.
• HELP explains what the question is asking and shows the response choices.
• Persistent bottom buttons while triaging:
    DEFINITIONS
    FULL STATUTE / FULL STATUTES
• Charge-specific definitions include plain-language field cues and a hyperlink to the controlling statute/definition.
• “Apprehension of imminent physical injury” is identified as a field cue rather than falsely presented as a separately defined Arkansas Code term.
• The statute button updates as answers narrow the applicable assault statute.
• Final result is summary-first:
    likely charge
    exact subsection
    classification
    max penalty
    why correct
    warrantless-arrest result
  Detailed elements, enhancements, report support, and sources are collapsible.
• V2.2 legal logic, Fort Smith ordinance library, special-vehicle triage, and infographic library remain.

UPLOAD
1. Extract the ZIP in Files.
2. GitHub > ArkansasLawDog/arkansas-charge-triage.
3. Add file > Upload files.
4. Select EVERY extracted file once.
5. Commit directly to main.
6. Leave GitHub Pages on main / (root).
7. Wait about one minute and refresh.
8. Confirm: V2.3 • Field Mode.
9. Fully close/reopen the Home Screen app.
